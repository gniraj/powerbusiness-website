# PowerBusiness — marketing site

Static site for the PowerBusiness hotel entertainment platform. No build step.

- `index.html`, `styles.css`, `script.js` — the page
- `assets/` — product screenshots from the prototype
- `vercel.json` — clean URLs + asset caching

Deploy: `vercel --prod` (project `powerbusiness`).  
Before launch: set `CONTACT_EMAIL` in `script.js` or wire the pilot form to a form backend.
